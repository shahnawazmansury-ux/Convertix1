# Convertix
Convertix is a modern, responsive web application that allows users to seamlessly convert numbers between Binary, Decimal, Octal, and Hexadecimal number systems. Built using HTML, CSS, and JavaScript, it features a sleek dark-themed interface, real-time validation, conversion history, and a user-friendly experience.
# Features
🔄 Convert between:\
Binary ↔ Decimal\
Binary ↔ Octal\
Binary ↔ Hexadecimal\
Decimal ↔ Octal\
Decimal ↔ Hexadecimal\
Octal ↔ Hexadecimal\
✅ Input validation for all supported number systems\
📋 Copy converted results to the clipboard\
🌙 Dark/Light theme toggle\
🕘 Conversion history using Local Storage\
📱 Fully responsive design for desktop and mobile\
